# Discord Bot TKA (No ENV - Vercel)

## Cara Pakai
1. Isi config di `api/interaction.js`
2. Upload ke Vercel (ZIP)
3. Set Interaction Endpoint:
   https://PROJECT.vercel.app/api/interaction
4. Daftarkan slash command `/start`

## Fitur
- /start → panel belajar
- Button timer 20 menit
- Notifikasi ke #tka-log
- TANPA ENV, semua di file
